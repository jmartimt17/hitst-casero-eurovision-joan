# 🎵 Hitster Eurovisión 2024

Versión DIY del juego Hitster con todas las canciones de la Gran Final de Eurovisión 2024 (Malmö, Suecia).

## Archivos

- `play.html` → La web que abre cada QR. Muestra el país y el temporizador de 20s.
- `cards.html` → Generador de cartas imprimibles con QR.

## Cómo desplegar en GitHub Pages

1. Crea un repositorio en GitHub llamado `hitster-eurovision`
2. Sube estos dos archivos (`play.html` y `cards.html`)
3. Ve a Settings → Pages → Source: `main` branch → `/root`
4. Tu web estará en: `https://TU-USUARIO.github.io/hitster-eurovision/`

## Cómo generar las cartas

1. Abre `cards.html` en tu navegador (o en GitHub Pages)
2. Introduce tu URL base: `https://TU-USUARIO.github.io/hitster-eurovision/play.html`
3. Pulsa "Actualizar QR"
4. Imprime la página (Ctrl+P) → Los QR se imprimen en blanco y negro perfectamente

## Cómo jugar

1. Escanea el QR de una carta con el móvil
2. Pulsa "Abrir en Spotify" → la canción se abre en tu app de Spotify
3. Dale play en Spotify
4. Pulsa "Iniciar temporizador" en la web → cuenta atrás de 20 segundos
5. ¡Adivina el año del Festival en que participó esa canción!
